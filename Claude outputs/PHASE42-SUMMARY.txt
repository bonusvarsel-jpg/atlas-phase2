🎯 QUICK START (Mac)
═══════════════════════════════════════════════════════════════════════════

  Step 1: Create directory
  $ mkdir -p ~/atlas-phase42 && cd ~/atlas-phase42

  Step 2: Follow PHASE42-MAC-INSTALL.sh
  $ bash PHASE42-MAC-INSTALL.sh
  (or copy-paste each STEP 2-7 manually)

  Step 3: Verify locally
  $ npm install
  $ npm start
  $ open http://localhost:3000

  Step 4: Deploy to Railway
  $ railway link          # Create/select Railway project
  $ railway up            # Deploy to cloud
  $ railway open          # View live dashboard
