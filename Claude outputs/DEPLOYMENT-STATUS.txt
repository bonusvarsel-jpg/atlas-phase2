  → Deploys to Railway cloud
  → Prints live URL

$ railway open
  → Browser opens dashboard

📞 IF SOMETHING GOES WRONG
═══════════════════════════════════════════════════════════════════════════

Error: "railway command not found"
→ Install: npm install -g @railway/cli@latest

Error: "Build failed"
→ Check logs: railway logs
→ Verify locally: npm start (should work)

Error: "Can't connect to live URL"
→ Wait 2-3 minutes, Railway is building
→ Check status: railway status
→ View logs: railway logs -f

Error: "API returns 404"
→ Check URL has /api/ prefix
→ Verify deployment completed
→ Check logs for startup errors
